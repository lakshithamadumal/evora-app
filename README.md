# 🌸 Evora Perfume Selling app

Evora is a modern Android perfume shopping application that allows customers to browse products, place orders, and make secure online payments.

## ✨ Features

* Browse perfume collections
* Product search and filtering
* Shopping cart management
* Secure PayHere payments
* User authentication
* Order tracking
* Responsive mobile interface

## 🛠️ Built With

* Android (Java)
* Firebase
* PayHere

## 🚀 Getting Started

```bash
git clone <https://github.com/lakshithamadumal/evora-app.git>
```

Open the project in Android Studio and run the application.
